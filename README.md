# 2048 Sandbox

每次尝试都有来处，每一步都可以回看。经典 2048 与可扩展规则沙盒。

**当前版本：v0.9.0，跨平台发布。** 提供安卓离线安装包、本地程序 ZIP、静态网页 ZIP 和单文件 HTML。源码、设计材料、测试与构建入口均在本仓库中；程序包不包含个人对局或签名私钥。

- [在线试玩 · 云枢](https://2048-sandbox.yijianyu.hub2.cloud/) / [备用网页版 · GitHub Pages](https://sincostancscseccot.github.io/2048-sandbox/)
- [安卓 APK](https://github.com/sincostancscseccot/2048-sandbox/releases/download/v0.9.0/2048-sandbox-v0.9.0-android.apk) / [全部下载与历史程序包](https://github.com/sincostancscseccot/2048-sandbox/releases/tag/v0.9.0)
- [安卓安装与构建说明](android/README.md) / [网页发布说明](docs/release/网页发布说明.md) / [跨平台发布验收](docs/planning/跨平台发布_验收记录.md)

云枢与 GitHub Pages 均已上线，并通过真实地址的移动、保存恢复、备份导出/导入及断网重开验证。不同网页地址、浏览器和安卓应用使用各自的本地存储，可通过 `.2048backup` 完整备份迁移对局。

此前的[键盘修复](docs/planning/键盘操作修复_验收记录.md)、[显示与对局管理](docs/planning/显示修复与对局管理_验收记录.md)、[动效与音效](docs/planning/动效与音效_验收记录.md)、[M6 验收](docs/planning/M6_验收记录.md)与[性能记录](docs/planning/M6_性能记录.md)继续保留。

## 开始试玩

在已安装依赖并生成生产构建的源码工作区中，双击根目录的 **启动试玩.cmd**，保持启动窗口运行，再打开 [http://127.0.0.1:4173/](http://127.0.0.1:4173/)。新检出先按“开发与验证”安装并构建。也可在项目目录执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\start.ps1
```

需要可携带的程序时，使用 [v0.9.0 本地 ZIP](https://github.com/sincostancscseccot/2048-sandbox/releases/download/v0.9.0/2048-sandbox-v0.9.0.zip)。完整解压后运行包内“启动试玩.cmd”，只需 Node.js 24.19+（24.x），无需安装 pnpm 或项目依赖。包内含使用说明、文件摘要和第三方许可；[校验和与发布入口](release/README.md)。程序 ZIP 不含个人对局，游戏数据应另外导出备份。

初次打开点击“开始经典对局”，或通过“自定义新局”设置行列、数字权重、生成数量、目标和技能。方向键、WASD、常规棋盘滑动和方向按钮均可操作；大棋盘使用滚动查看与方向按钮移动。每次成功操作保存后才显示新棋盘；刷新或关闭页面后恢复最后保存位置。“新开一局”沿用当前规则并保留旧局，设置窗口也可直接开始固定经典局。

顶部“返回首页”或品牌图标回到欢迎页，不改保存节点；“继续已保存的对局”可重新打开记录。“我的对局”每条记录旁的“删除”需要确认，会删除整局历史与检查点，无法撤销；其他对局和已导出的备份保留。有尚未确认的保存时，先重试或重新读取保存进度，再返回首页或删除。

展开“我的对局”不会暂停正在玩的对局，WASD 和方向键继续有效。每次按下处理一步，长按不连走；保存时的方向输入不会滚动网页。输入框、弹窗和首页使用各自正常的键盘行为。

基础沙盒默认开启撤销 3 次。撤销恢复最近操作前的棋盘、成绩和世界回合，同时从当前资源扣除次数、增加有效操作数并保存新节点。删除、交换、升级、降级、洗牌、放置、清空行列和旋转可在新局设置中开启；选格与取消免费。详细规则见 [M3 操作说明](docs/design/基础沙盒_M3.md)。

左侧“编辑本节点棋盘”支持画笔、擦除和草稿撤销/重做；“修改本节点规则”预览尺寸迁移并发布新版本。提交均创建新子节点，旧路径保留；规则版本边界清空技能撤销栈，历史导航仍可跨版本。“高级规则”可设置映射、连锁、数列、位置与阶段生成，以及触发/条件/动作。详见 [M4 操作说明](docs/design/高级沙盒_M4.md)。

M5 增加矩形区域填入/擦除、设置导航、变量改名时同步引用，以及事件/动作复制和动作排序。“规则与路径统计”提供精确路径指标、可回看的趋势图、事件运行状态和节点差异；可下载独立分析 JSON。从历史预览新开一局会沿用正在展示的规则版本。详见 [M5 操作说明](docs/design/交互与统计_M5.md)。

M6 在“自定义新局”增加连锁合并、斐波那契、技能练习场和阶段奖励预设。选择只填写草稿，创建才保存；[规则 JSON](examples/presets/README.md) 可从文件中心导入。右上角“帮助”在欢迎页、对局和离线状态均可打开。完整用法见 [本地版使用说明](docs/release/本地版使用说明.md)。

右上角“动效与声音”可分别开关滑动动画、游戏音效和氛围光影，调整音量或试听；棋盘下方有动画/音效快捷按钮。默认音量 30%，偏好记在当前浏览器。系统开启减少动态效果时自动使用静态展示；密集棋盘也会简化。音效可离线使用，静音或切到后台会停止播放，历史回看不重复播放。

点击历史节点可以免费回看，分数读取该节点的完整状态。“从此继续”只选定父节点，下一次有效移动才保存分支；默认重抽，也可选择复现。相同状态可以共用快照，历史节点始终保留各自的 ID。

“打开完整历史树”支持平移、双指缩放、总览定位、路径高亮、折叠、节点查找与只读回放。节点详情可进入路径统计、导出节点/路径，以及归档或恢复分支。树按视口显示，主页面历史列表每页 60 条；归档只改标记，完整备份始终保留这些记录。

“文件与恢复”可导入预览并创建独立副本，也可选择导出范围；“导出备份”直接下载整库 .2048backup。导入支持新容器和旧 M1 JSON，同一文件可重复导入而不覆盖原局。需要演示文件时，使用 [示例存档](examples/projects/README.md)。

页脚显示“离线资源已就绪”后，同一地址可断网重开和继续。开发服务器不提供 PWA 离线验收。浏览器按来源隔离数据：**127.0.0.1:4173、localhost:4173 和开发端口 5173 是不同存储空间**，日常试玩请固定使用同一地址。

旧版本已打开时，使用页脚的新版本提示完成更新，并刷新其他旧版页签。M1 数据库会自动迁移，棋盘、成绩、历史与活跃位置保留。

## 开发与验证

建议 Node.js 24.19+（24.x）与 pnpm 11.25.0。依赖直接版本已锁定，完整解析结果在 pnpm-lock.yaml；新检出先运行安装：

```text
pnpm install --frozen-lockfile
pnpm dev
```

开发地址为 http://127.0.0.1:5173/。当前机器的包管理器命令不可用时，可使用 Windows 入口启动已有依赖：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\start.ps1 -Development -Port 5173
```

验证命令：

```text
pnpm typecheck
pnpm test
pnpm validate:design
pnpm build
pnpm test:e2e
pnpm test:performance
pnpm test:release
pnpm release:local
pnpm preview --port 4173 --strictPort
```

`build` 包含完整类型检查。`test:e2e` 检查生产构建，自动启动或复用 4173 的本机服务器；使用已安装的 Chrome，缺少 Chrome 时先安装或调整 playwright.config.ts 的 channel。浏览器测试操作隔离的临时对局，并在更新测试中临时改写、随后恢复 dist/sw.js；请勿与构建同时运行。HTML 报告在 playwright-report/，当前原始结果在 .work/management-e2e.json，M6 历史汇总保留在 .work/m6-verification.json。`test:performance` 独立测量完整引擎/存储/容器流程，`test:release` 检查已生成的程序包；首次先运行 `release:local` 构建打包。

修改源码后重新运行 `pnpm build`，或执行 `scripts/start.ps1 -Rebuild` 更新生产试玩。启动脚本只在 dist/ 不存在时自动构建，已有构建不会被隐式覆盖。默认使用原生 Node HTTP 服务，Ctrl+C 停止服务器。

## 游戏与保存

- 经典 4×4、每步每块合并一次、9:1 生成 2/4、精确整数计分、胜利后继续与无路可走结束。
- 独立纯引擎、版本化 PCG32、完整状态摘要和确定性回放校验。无效移动不写节点、不推进计数、不抽随机数。
- 节点、快照、规则、项目头在同一 IndexedDB 事务提交；失败整体回滚，重试保留同一 operationId 和随机输入。
- 多页面版本冲突提示、存档完整性检查、节点列表、检查点、旧节点继续，以及对局库。
- 生产 PWA 资源缓存；新版本等待当前保存确认后才允许刷新。
- 完整历史树、只读路径回放、节点查找、分支折叠与归档恢复。
- 导出规则 JSON、单节点 .2048state、单路径/完整对局 .2048lab，以及整库 .2048backup；导入前校验并预览，写入独立副本。
- 默认 DEFLATE 无损压缩、内容哈希去重；根与检查点保存完整快照，普通节点可用有界增量链恢复。
- M1 JSON 兼容导入和 IndexedDB 自动升级；重复导入保持状态摘要、节点 ID、分数与随机流。
- 基础自定义配置校验、可变尺寸棋盘、非负精确数字、目标与生成策略；九种基础技能及其次数、成本、冷却和恢复。
- 撤销恢复世界状态，当前资源账本与随机流继续；技能也支持分支、确定性回放和完整备份恢复。
- 棋盘草稿编辑、尺寸迁移与不可变规则发布；每个历史节点使用自己的规则版本。
- 映射/相邻数列合并、有上限的连锁、位置权重、按条件切换生成阶段，以及有预算的触发/条件/动作。
- 批量矩形草稿、引用同步与动作排序；精确路径统计、运行状态、节点对比与独立分析报告。
- 历史树总览、路径高亮、键盘/双指导航和视口索引；列表与逐步统计分页显示。
- 提交按主键读取本步依赖，整库共享规则/快照单次校验，完整打开仍逐节点回放；导入检查可取消，选择位置与活跃节点一致。
- 四套实际玩法预设、离线帮助、原生本机服务、可携带程序包、文件摘要与第三方许可原文。
- 独立方块层的滑动/合并/出现反馈、离线合成音效、音量和开关；系统减少动态效果、后台静音和设备偏好记忆。

备份从同一只读事务获取一致数据；整批导入在一个写事务中提交，空间不足时整体回滚，重试沿用同一批副本 ID。每个副本拥有自己的项目命名空间，底层相同快照仍可共享。同一对局可包含多个规则版本，文件边界见 [存档格式 v1](docs/design/存档格式_v1.md)。计时、墙/保护格、非方形直角旋转和未知规则只读导入留待后续；未知能力或格式不会猜测执行。

数据保存在当前浏览器的 IndexedDB，不依赖账号或在线服务。定期导出可保留完整记录。发生保存错误时，棋盘保留最后确认的状态；可重试同一笔保存，或明确选择“重新读取已保存”放弃未确认操作。损坏的存档不会被悄悄替换成新局；备份校验失败时提供原始恢复 JSON，并明确提示它不是已验证的完整备份。

## 后续

M0–M6 的既定本地范围已完成，可进入实际试玩与反馈修复。跨平台发布见上方下载与网页入口；计时、保护格和未知能力只读导入等功能仍需单独细化。当前规模证据见性能记录，完整撤销栈较长时，读取和保存确认仍可能需要数秒。
