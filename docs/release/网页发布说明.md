# 网页发布

在线版：[云枢](https://2048-sandbox.yijianyu.hub2.cloud/)。备用在线版：[GitHub Pages](https://sincostancscseccot.github.io/2048-sandbox/)。源码与下载入口：[GitHub](https://github.com/sincostancscseccot/2048-sandbox)。两个实际 HTTPS 地址均已通过移动、保存恢复、完整备份导出/导入及断网重开验证。

## 发布文件

所有程序文件位于 [v0.9.0 发布页](https://github.com/sincostancscseccot/2048-sandbox/releases/tag/v0.9.0)。

| 文件 | 用途 |
|---|---|
| `2048-sandbox-v0.9.0-cloud.zip` | 云枢专用 Node.js 22 项目，根目录含 package.json，监听 PORT 和 0.0.0.0 |
| `2048-sandbox-v0.9.0-web.zip` | 静态站点文件，根目录直接包含 `index.html`、资源和离线缓存；支持放在子目录 |
| `2048-sandbox-v0.9.0-web.html` | 单文件平台上传，脚本、样式、图标与许可均内置；无需额外 CDN 或资源文件 |
| `2048-sandbox-v0.9.0.zip` | 附本机启动器和校验工具的本地程序包 |
| `2048-sandbox-v0.9.0-android.apk` | 安卓离线安装包 |

优先使用静态 ZIP，以保留首次访问后的离线重开和更新提示。若平台只接受 HTML，则上传单文件 HTML。单文件版在页面打开后可运行，重新打开仍需要平台可访问；不注册该平台根目录的 Service Worker。

均需通过 HTTPS 或 localhost 提供页面；不要将静态 ZIP 里的 `index.html` 直接双击作为正式部署。平台嵌入时须允许脚本、本地持久化存储、文件选择与下载，否则备份或保存功能无法正常使用。

## 重新构建

```powershell
pnpm install --frozen-lockfile
pnpm release:local
pnpm release:web
pnpm build:pages
pnpm release:cloud
```

`build:web` 输出相对路径静态文件至 `.work/web/`；`build:single` 输出用于合并的单包资源至 `.work/single/`；`package-web.mjs` 生成 ZIP、单文件 HTML 和摘要。`build:pages` 输出适用于 `/2048-sandbox/` 的文件至 `.work/pages/`；部署其他固定路径时可设置 `SANDBOX_BASE`。GitHub Pages 使用 `gh-pages` 分支的根目录，发布前添加 `.nojekyll` 和第三方许可。

网页版、安卓与本地版使用独立存储。换平台或网页地址前应导出备份，不会自动同步个人对局。
