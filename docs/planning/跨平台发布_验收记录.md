# 跨平台发布验收

版本：v0.9.0。日期：2026 年 10 月 15 日。

## 交付范围

公开仓库保留源码、设计基线、示例、测试及构建入口；生成的程序由 [GitHub Release](https://github.com/sincostancscseccot/2048-sandbox/releases/tag/v0.9.0) 分发。当前产品包含本地 ZIP、正式签名安卓 APK、静态网页 ZIP、单文件 HTML 和云枢专用 Node.js 22 ZIP；四份既有历史 ZIP 保持原始字节，附于此次发布，不虚构历史 Git 源码快照。

游戏规则、PCG32 随机算法、数据库版本和存档容器版本保持兼容。网页来源、浏览器与安卓应用分别保存数据，使用 `.2048backup` 迁移，不提供自动云同步。

## 验证结果

| 验证 | 结果 | 覆盖 |
|---|---|---|
| 单元与存储测试 | 197 项通过 | 引擎、规则、历史、事务、存档、展示及原生下载反馈 |

| 正式 APK 运行 | 18 项通过 | 首次离线、自动保存、真实系统文档导出/取消/导入、独立副本及返回键 |
| 发布包检查 | 9 项通过 | 摘要、原生本机服务、路径限制、实际云枢 ZIP 入口与 PORT 绑定 |
| 托管路径检查 | 两种路径通过 | 相对 `/upload/` 和 Pages `/2048-sandbox/` 下移动、保存及断网重开 |
| 设计检查 | 通过 | 3 份 Schema、引用和状态摘要、撤销计费、6 组随机输出及 279 个本地链接 |
| 类型检查与生产构建 | 通过 | 本地、网页、单文件、Pages 和安卓构建 |

安卓使用 Android 15 / API 35 模拟器、WebView 124.0.6367.219，测试对象为正式签名的 Release APK，测试代码不进入产品 APK。模拟器关闭网络后完成上述流程；尚未进行实体手机兼容性验收。应用要求 Android 8+ 和现代 WebView，详见[安卓说明](../../android/README.md)。

生产校验器由与开发版相同的 Schema 和 AJV 配置在构建期生成，不需要运行时动态编译。安卓保持严格内容安全策略及应用内 HTTPS 资源来源，APK 不申请网络或广泛存储权限，导入导出通过系统文档选择器完成。

## 文件与签名

每份产品附同名 `.sha256`；本地程序和网页包包含实际第三方许可，APK 合并网页及原生依赖许可。安卓公开签名证书 SHA-256：

```text
43a9b696fc299d23b4f401bb1d6410780f5e42f70f162345b3adb5145f6eedb5
```

签名私钥及 Windows DPAPI 保护的密码位于被忽略的 `.private/`，不进入源码、网页或发布附件。SDK、开发依赖、构建缓存和个人对局均不进入交付。未来安卓更新须沿用此签名私钥。

## 托管状态

备用网页版：[GitHub Pages](https://sincostancscseccot.github.io/2048-sandbox/)。构建路径和部署方式见[网页发布说明](../release/网页发布说明.md)。

云枢已接收项目 ZIP 并创建部署项目，但平台在创建 Docker 网络时返回 `all predefined address pools have been fully subnetted`，应用尚未启动，SSL 仍在申请中。当前不能把云枢预分配域名当作可用试玩地址。平台运行环境恢复后需重新部署，再验收实际游戏及备份流程。
