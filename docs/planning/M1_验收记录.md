## 2 状态与事务

引擎接收完整状态、不可变经典规则、动作、父节点 ID 和显式随机输入。它不读取现实时间或外部随机数，所有生成与新方块 ID 都可确定性复现。数字保存为十进制字符串，计分使用 BigInt；测试覆盖超过 Number 安全整数的成绩。

无效移动不创建节点、不推进有效操作/回合/随机流。失败的资源检查不修改输入。每个成功节点包含独立 ID、父节点、动作、完整状态哈希、operationId 和前后随机流。预览与检查点不计入游戏操作。

摘要、Schema 校验和回放复核在 IndexedDB 事务之外完成。一个写事务插入规则/快照/节点并更新项目头和最后保存对局；旧版本冲突拒绝覆盖。UI 只在提交与读取确认后展示新棋盘。失败保留原候选，重试不重新生成节点 ID、随机输入或成本。

恢复检查 Schema、SHA-256、引用、父子深度、规则版本和每个非根节点的确定性回放。历史回看读取保存结果；从旧节点的新操作默认使用新随机上下文，可选复现父节点随机流。同状态快照去重时仍保留独立节点。

## 3 自动检查

本机 Node.js 24.19.0、pnpm 11.25.0；全部直接依赖见 [package.json](../../package.json)，解析版本见 [pnpm-lock.yaml](../../pnpm-lock.yaml)。补齐了 PWA 需要的 workbox-window / workbox-build 7.4.1，并分离校验库资源。生产资源缓存清单为 9 项、约 510 KiB。

```text
pnpm typecheck          通过（也包含于 build）
pnpm test               35/35 通过
pnpm build              通过，生成 dist/ 和生产 Service Worker
pnpm test:e2e           7/7 通过，隔离 Chrome
pnpm validate:design    通过
```

单元检查入口为 [引擎测试](../../tests/unit/engine.test.ts)与[存储测试](../../tests/unit/persistence.test.ts)。覆盖官方六个 PCG32 向量、序列恢复与拒绝采样、四方向顺序、禁止连锁二次合并、精确分数、胜利继续、无路可走、资源预算原子失败，以及 256 种四格组合在左右两个方向的守恒检查。

存储测试包括关库重开、同 operationId 幂等、节点/状态写入后配额异常的整笔回滚、并发版本冲突、同状态独立节点、检查点不计步、错误计分候选在写入前拒绝，以及摘要/快照/父节点/随机记录损坏拒绝。

## 4 真实浏览器证据

生产预览地址为 127.0.0.1:4173。浏览器测试入口：[game.spec.ts](../../tests/e2e/game.spec.ts)。

| 流程 | 结果 |
|---|---|
| 鼠标方向按钮后直接使用键盘，进行六步；保存检查点；关闭页签再打开 | 节点 ID、分数、有效操作、完整状态与随机流一致 |
| 根节点预览、选择继续、复现与重抽 | 预览/选定父节点均不写游戏节点；复现同状态保留独立节点；原路径完整 |
| 两页读取同一版本，一页先保存 | 第二页收到版本冲突，重新读取后恢复已保存位置 |
| 完成生产缓存后关闭页面、断网再打开、继续一步并刷新 | 恢复并继续成功，离线新节点确实落库 |
| 390×844 手机视口，经 Chrome 原生触摸事件滑动 | 有效移动写入一次；方向按钮可用，无横向页面溢出 |
| 修改保存快照但保留原摘要，再重新打开 | 明确提示完整性错误，不新建对局覆盖；仍能导出原始库 |
| 在项目头写入时注入空间不足，连续重试，再触发真实 SW 更新 | 所有写入回滚；两次候选完全相同；更新按钮等待保存确认；刷新后节点未重复 |

第一个浏览器流程导出的 JSON 经解析检查，包含七个节点与检查点；备份单元测试额外验证多对局与规则的完整集合。实际执行报告在 .work/m1-e2e.json 与 playwright-report/，这两个目录为可再生的忽略文件。

桌面 1280×720 与手机 390×844 的完整页面截图已视觉复核。留存图为 [桌面](assets/m1-desktop.png)和[手机](assets/m1-mobile.png)，来自隔离测试数据。

- 支持经典规则；自定义、技能、编辑棋盘和计时对局尚未开放。完整状态中的相关字段为后续保留。

- M1 JSON 可导出完整库；应用内文件导入/备份恢复尚未实现。该格式使用独立标识，不冒充正式 .2048lab/.2048backup 容器。
- 历史采用节点列表，首次显示最近 60 个并可展开；恢复和保存确认会校验完整对局。未声称大规模历史的性能达标。
- 离线检查覆盖本机 Chrome 和同一来源下的生产资源缓存；桌面安装流程、其他浏览器和跨设备迁移尚未单独验收。
