| 尺寸迁移 | 左上角坐标对齐，溢出取消/搬移/丢弃预览，空间不足和预算冲突拒绝 |

## 2 核心语义与回归

规则变化创建新子节点，不重算旧节点成绩。旧节点继续时保留原棋盘尺寸、技能与生成规则；规则池按状态引用加载，完整回放同时使用父规则和显式发布的新规则。

编辑/发布各增加一次有效操作，不推进计费回合，不主动生成数字或消费随机流；配置的编辑后事件在提交前执行。普通编辑可入技能撤销栈，版本变化则清空栈形成边界。原路径、免费导航和旧节点继续保持可用。

验证 `[2,2,4,8,空]` 的默认/连锁上限 2/3 结果与加分分别为 `[4,4,8,空,空]` /4、`[8,8,空,空,空]` /12、`[16,空,空,空,空]` /28。图形化高级规则示例将 2+4 映射为 16，格 4 生成 7，回合事件加 10 分、moves 加 1，首步成绩为 26。

递归 emit 事件消耗共享 10000 单位预算后，棋盘、随机流、计数、资源、有效操作和数据库均保持原状态；规则可修正后继续。实际浏览器中途注入 IndexedDB 配额失败，规则/状态/节点整体回滚，重试仅产生一个版本和一个节点。

## 4 浏览器完整流程

[m4.spec.ts](../../tests/e2e/m4.spec.ts) 增加 8 条流程，M1 的 7 条、M2 的 5 条、M3 的 8 条继续通过。测试使用隔离 Chrome 上下文和生产构建，不操作用户现有对局。

| 流程 | 证据 |
|---|---|
| 经典棋盘编辑 | 草稿撤销/重做与取消免费，键盘不误走；超安全整数精确保留，一步派生自定义，刷新后完整一致 |
| 缩小与旧分叉 | 取消策略阻止溢出，丢弃/搬移预览明确；成功搬移后旧节点仍用旧尺寸和旧规则 |
| 图形高级规则 | 映射、位置、阶段、事件变量通过真实表单设置，结果与引擎预期一致 |
| 离线恢复与发布 | 高级备份导入空浏览器，断网刷新后可再发布规则，源库完全未改 |
| 数列与连锁 | 真实表单控制连锁次数；相邻数列合并及升级技能结果正确 |
| 递归预算失败 | 提示预算耗尽，完整数据库未变化；限制执行次数后发布并继续 |
| 配额故障 | 写项目头时失败，新增规则与节点一起回滚；同笔重试只提交一次 |
| 手机与多版本备份 | 390×844 无横溢，编辑/迁移按钮可达；三规则版本和全部状态在空浏览器恢复 |
