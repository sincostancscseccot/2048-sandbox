# 键盘操作修复验收

日期：2026 年 10 月 15 日。应用版本：v0.8.3。

## 原因与修复

v0.8.2 将展开的“我的对局”列表包含在游戏阻止条件中，因此删除其他对局后，列表仍展开时无法用 WASD 或方向键移动；方向键的浏览器默认滚动仍会执行。另一个遗漏是按键重复和保存中的提前返回未阻止页面滚动。

“我的对局”从弹窗阻止条件中移除。只有实际弹窗、只读预览、保存/错误、技能选择及结束状态限制游戏动作。非编辑区域的游戏方向输入先阻止浏览器默认滚动，再检查是否允许执行；保留每次按下处理一步的行为，长按或保存中不会排队重复移动。

文字、数字、下拉框与可编辑内容保留自身键盘行为；组合快捷键、已由子控件处理的事件、真正的弹窗及首页不被游戏抢占。删除确认仍阻止底层游戏操作。

## 浏览器回归

- 删除其他对局后保持列表展开，在滚动过的页面依次使用 d/s/a/w 和四个方向键；棋盘连续保存 8 步，页面滚动位置不变。
- 暂停一次真实摘要计算以保持“保存中”，发送实际方向键长按重复及另一个方向输入；不滚页、不追加操作；保存完成后仍忽略重复事件，只有一个新节点。
- 数字输入框的方向键正常增值，名称可输入 wasd；弹窗内按键不改变已保存对局，回到首页后方向键恢复正常页面滚动。
- 同时复核原有键盘/历史/多页签冲突、手机滑动、离线缓存、配额重试、PWA 更新、主页和对局删除场景。

新增 3 条键盘回归及既有 14 条相关页面流程全部通过，共 17 条实际 Chrome 流程。严格类型检查、生产构建和 8 项发布检查通过，包含实际 Windows PowerShell 5 启动、程序包与当前构建逐文件一致、重复打包摘要一致。原始浏览器结果为 `.work/keyboard-e2e.json`，文件摘要与校验汇总为 `.work/keyboard-verification.json`。
