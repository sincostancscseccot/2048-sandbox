# v0.8.1 动效、音效与外观优化

## 使用

右上角 **动效与声音** 打开设置。滑动动画、游戏音效和氛围光影分别开关，音量默认 30%，可试听合并音效。棋盘下方也有动画和音效的快捷按钮。默认启用三项效果，系统开启“减少动态效果”时使用静态展示。

选择保存在当前浏览器的同一站点地址下，并同步到其他同源页签。设置仅影响当前设备的呈现，不进入游戏规则、历史节点或 `.2048backup`；浏览器不允许保存偏好时，本次设置仍可使用。

## 行为

| 请求 | 实际表现 |
|---|---|
| 数字滑动过程 | 独立方块层呈现约 160 ms 滑动；两个参与合并的旧方块到达目标后消失，合并结果弹出，新生成数字随后出现 |
| 高级合并 | 使用当前节点规则追踪连锁、映射和相邻数列的来源与目标，不将所有新数字当成普通生成 |
| 技能与连续输入 | 交换、旋转等保留 ID 的方块可移动，撤销/编辑采用对应状态变化；新操作与窗口缩放会清理旧动画，输入不因动画另加等待 |
| 音效 | 移动、合并、撤销、技能、编辑、开局、胜利、失败和无效移动有不同提示；浏览器原生合成，离线可用，无外部素材下载 |
| 成功确认 | 成功画面和声音依据已确认保存的节点；失败不提前播放成功音效，同一笔保存重试不重复反馈 |
| 历史与恢复 | 预览、回到当前、重新读取、检查点和导入读取不重复触发游戏音效；只有实际的新操作产生反馈 |
| 静音与后台 | 关闭音效或音量归零停止正在播放和已排程的提示音；页面进入后台停止声音，首次用户操作后才启用音频上下文 |
| 美化 | 增加纸色渐变背景、棋盘柔光、方块细节阴影与精确成绩变化提示；可通过氛围开关关闭 |
| 适配与预算 | 非方形棋盘按实际正方形格子排版；前后两帧合计超过 128 个占用格时使用静态结果，避免密集棋盘创建过多动画 |

保存格式、随机流、计分、技能和事件结算不变。轨迹属于展示计算，所有最终数字仍读取已保存状态；动画和音效不调用游戏随机数，也不写入对局。

## 验证

新增 [presentation.test.ts](../../tests/unit/presentation.test.ts) 10 项，验证四种合并方式、四方向共 480 组轨迹与真实引擎结果一致，来源方块不丢失/重复、输入不变、连锁目标、精确大数、偏好容错、声音解锁/排程/静音/降级和成功反馈分类。

新增 [experience.spec.ts](../../tests/e2e/experience.spec.ts) 7 条实际 Chrome 流程：

- 暂停在真实动画中间帧，检查保留方块与被合并方块的位置在起点/终点之间；合并数字尚未提前显示，完成后格子与方块严格对齐。另检查连锁四个来源到达同一目标。
- 使用真实 AudioContext 与分析器检查非零音频信号；静音、音量 0、保存失败、同笔重试、历史与检查点均按预期处理。
- 390×844 设置面板、开关保存与跨页签同步；改设置前后游戏数据库完全一致。
- 系统减少动态效果、偏好存储被拒绝时仍能操作，关闭动态后没有方块动画。
- 连续八次方向键与窗口缩放不留下幽灵方块，最终方块 ID 与保存状态完全一致。
- 离线重开、设置、试听、动画、操作保存和再次刷新恢复可用。
- 计步但棋盘不变时越过滑动计时边界后仍处于空闲状态；9×9、70 个数字的密集棋盘使用静态结果。

最终通过 **184 项单元/存储/格式测试（11 个文件）、48 条实际浏览器流程、8 项发布检查**，严格类型检查和生产构建成功。浏览器全量结果无跳过、无重试通过；原有撤销、编辑、规则版本、历史、离线、配额回滚和千节点完整恢复流程继续通过。

生产包通过原生服务、Windows PowerShell 5 入口、文件摘要与可重复打包检查；预缓存 24 项、约 740 KiB。文件摘要核对 95 个应保留文件，结算引擎、回放验证、存储仓库、Schema、容器、依赖锁、原稿及 M6 发布 ZIP 保持原样。本轮未增加依赖。

最新版为[本地程序 v0.8.1](../../release/2048-sandbox-v0.8.1.zip)，更新后仍需使用同一浏览器和站点地址。页脚出现新版本提示时点击更新，以载入新画面与开关。工作区原始结果在 `.work/experience-e2e.json`，汇总在 `.work/experience-verification.json`。
