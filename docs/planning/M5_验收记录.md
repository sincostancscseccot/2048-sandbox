## 1 交付范围

| 范围 | 实际行为 |
|---|---|
| 批量草稿 | 矩形双角填入/擦除，整批撤销/重做，提交前可取消；一批仍是一笔有效操作 |
| 图形规则 | 设置导航、组合条件保留和摘要、变量引用同步、事件/动作复制与动作排序 |
| 运行状态 | 当前预览原规则、目标、阶段、变量、事件执行次数/冷却/条件、技能资源 |
| 路径统计 | 唯一父链口径、最高成绩/最大数字/操作/合并/版本/检查点，撤销下降正确 |
| 分析回看 | 固定统计终点，图表/滑块/逐步记录免费预览，筛选与分页，完整统计 JSON |
| 节点比较 | 坐标与尺寸差异、成绩、规则、随机流、资源、变量和事件变化 |
| 历史树 | 视口索引、总览、路径高亮、定位/跟随、键盘焦点、真实双指缩放 |
| 列表和手机 | 历史每页 60 条，统计每页 50 条；手机区域编辑、窗口内布局和宽表格容器滚动 |
| 上下文一致 | 从历史预览新开一局沿用展示的规则版本，原项目与旧路径保持不变 |

无新增依赖，不修改规则能力、核心 Schema、数据库 v3 或存档容器 v1。游戏结算、事件、迁移和归档代码保持 M4 内容；JSON/Ajv 模块导入采用显式形式供浏览器测试进程复用纯引擎。v0.1 原稿、v0.2 Markdown/Word 和 M3/M4 演示材料保持不变。

| 树与焦点 | 父子键盘导航和焦点转移、视口平移、总览、保存位置定位、进入统计均不写数据 |
| 手机 | 390×844 区域编辑、分析窗口与树无横溢；通过 Chrome 实际双触点事件缩放后免费定位 |

统计读取已保存状态，经纯计算回到图表、表格与导出；游戏输入、节点候选、IndexedDB 提交和恢复链路沿用 M4。生产 HTTP 入口返回 200，预缓存 21 项、约 712 KiB，包含新增分析与总览模块。

## 4 规模证据与边界

10000 节点深链在 760×410、缩放 1 的指定视口中只查询少于 12 个节点/连线；3000 子节点交叉连线统计为 3000，返回绘制列表限制为 2000。真实浏览器验证的是 301 节点完整存档与上述显示预算，报告仍保留全路径。

这些结果分别证明布局/查询和实际导入交互，不等同于 10000 节点完整存储/回放已经验收，也不构成所有树形的固定帧率承诺。不同规模、树形和设备的系统性能留待 M6。
