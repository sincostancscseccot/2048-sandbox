# 2048 Sandbox 规则参数字典

**版本：** 补充设计 v0.1  
**日期：** 2026 年 10 月 14 日  
**依据：** [产品基线 v0.2](2048_Sandbox_功能与规则设计文档_v0.2.md) 第 13 节 D01–D12。

本字典将规则空间拆成可实现的字段。标有 D 编号的要求来自已确认决策；其他默认值是本轮提出的工程方案，可在实现前调整。第一阶段实现 M1 经典规则，M3 开放基础沙盒，M4–M5 开放高级规则，P2 项目留作实验扩展。

**M4 实现进展：** 基础参数与九种技能、棋盘编辑、规则版本迁移、自定义数列、映射/连锁、阶段生成和受控事件已实现，见 [M3 操作说明](基础沙盒_M3.md)、[M4 操作说明](高级沙盒_M4.md)和[M4 验收记录](../planning/M4_验收记录.md)。当前行列分别最多 64，棋盘最多 4096 格；计时、保护格和非方形 90/270° 旋转仍属后续范围。表中的阶段是设计开放顺序，具体完成范围以实际说明为准。

**M5 交互进展：** 参数语义保持 M4，新增条件摘要/组合保留、变量改名同步引用、事件/动作复制、动作排序和规则运行状态查看。图形界面与统计见 [M5 操作说明](交互与统计_M5.md)。

## 1 字段约定

| 类型或约定 | 含义 |
|---|---|
| `UInt` | 0 到 9007199254740991 的整数，溢出报错 |
| `IntText` | 非负精确整数的十进制字符串，如 `"0"`、`"2048"`；不接受负号、小数、指数或多余前导零【D07】 |
| `null` | 明确表示关闭、无限之外的“不适用”，不能代替数字 0 或空格 |
| 空格 | 棋盘格的 `tile` 为 `null`；数值为 `"0"` 的数字块仍占格 |
| 权重 | 非负整数；百分比只是界面显示，输入小数百分比先转换为整数比例并约分 |
| 坐标 | 零起始，`index = row × cols + col`；按行从左至右排列 |
| 对局中改规则 | 创建新规则版本和子节点【D09】，不原地修改旧节点；正常规则编辑后派生为自定义规则 |
| 项目设置 | 展示、重抽偏好、存储预算等不改变游戏规则的项目级字段，不直接生成游戏节点 |

规则字段路径相对于 `RuleSetVersion.definition`。各节标题标明界面位置；规则变化统一使用版本化提交，表中“新局”表示不能直接改变已有局面的含义，需新开局或提供明确的迁移动作。

## 2 棋盘

**界面：** 自定义设置 → 棋盘。正常模式固定经典值。基础尺寸在 M3 开放，格子和区域在 M4 开放。

| 字段 | 类型 | 默认值 | 合法范围与行为 | 阶段 |
|---|---|---|---|---|
| `board.rows` | UInt | 4 | ≥1；行列乘积不超过资源预算；1 行玩法允许并提示 | M1/M3 |
| `board.cols` | UInt | 4 | ≥1，独立于行数 | M1/M3 |
| `board.initialLayout` | 布局项数组 | `[]` | 每项为格子索引与 IntText；不重复、不越界；用于新局 | M3 |
| `board.cells` | 格子属性数组 | `[]` | 未列出的格子为普通格；禁用、墙、冻结等需声明能力 | M4 |
| `board.regions` | 区域数组 | `[]` | 区域 ID 唯一，格子引用合法；区域可以重叠 | M4 |
| `board.resizeAnchor` | 枚举 | `top-left` | 首版锚定左上；其他锚点后续开放 | M4 |
| `board.overflowPolicy` | 枚举 | `cancel` | 缩小时：取消、明确丢弃、按行顺序搬至空格；空间不足则取消 | M4 |

初始布局先放置明确指定的数字，再补足 `spawn.initialCount`。若明确布局已超过该数量，保留布局并给出提示，不删除玩家摆放的数字。墙阻断一条移动线；禁用格不接收数字，是否跨越空洞由对应能力的移动规范确定，未实现的格子类型不能静默当作普通格。

## 3 数字

**界面：** 自定义设置 → 数字。首版使用精确整数【D07】。

| 字段 | 类型 | 默认值 | 合法范围与行为 | 阶段 |
|---|---|---|---|---|
| `numbers.maxDigits` | UInt | 256 | ≥1；可调整的计算预算，超过上限拒绝该操作，不截断 | M1/M3 |
| `numbers.allowedValues` | IntText 数组或 null | null | null 表示允许预算内所有非负整数；数组去重；不限制合并结果时需明确提示 | M3 |
| `numbers.sequence` | 枚举 | `powers-of-two` | 用于预设与编辑辅助；自定义列表不自动改变合并算法 | M3/M4 |
| `numbers.customSequence` | IntText 数组 | `[]` | 自定义时至少两个不同数字，顺序保留；供邻接合并与升降级使用 | M4 |
| `numbers.specialTypes` | 类型定义数组 | `[]` | 特殊数字的类型和运行时属性分开保存 | M4/P2 |

256 位是建议的初始预算，不是已测得的性能上限。运算建议使用 BigInt，文件中使用 IntText；即使数字很大，也不能通过普通浮点数中转。数字显示缩写属于界面设置，展开或复制时提供完整值。

## 4 生成

**界面：** 自定义设置 → 生成。经典配置为开局两个数字，有效移动后生成一个，2 与 4 的权重为 9 与 1。

| 字段 | 类型 | 默认值 | 合法范围与行为 | 阶段 |
|---|---|---|---|---|
| `spawn.initialCount` | UInt | 2 | 可为 0；超出可用格数量时按空间策略处理 | M1/M3 |
| `spawn.initialWeights` | 权重项数组 | 2:9，4:1 | 与回合生成独立；每项含 `value`、`weight` | M1/M3 |
| `spawn.perActionCount` | UInt | 1 | 可为 0；只有本次命中生成触发条件时才使用 | M1/M3 |
| `spawn.weights` | 权重项数组 | 2:9，4:1 | 需要抽样时总权重大于 0，值不重复 | M1/M3 |
| `spawn.triggerOn` | 枚举数组 | `["move"]` | `move`、`round`；多个条件同时命中只运行一次生成阶段 | M3 |
| `spawn.emptyStrategy` | 枚举 | `fill-available` | 生成至填满、整批跳过；事件替代放在 M4 | M3/M4 |
| `spawn.positionStrategy` | 枚举 | `uniform` | 均匀或按位置权重；只从当前合法空格抽取 | M3/M4 |
| `spawn.positionWeights` | 索引权重数组 | `[]` | 使用位置权重时需存在正权重候选；已占格不参与 | M4 |
| `spawn.phaseRules` | 阶段规则数组 | `[]` | 依回合、分数或事件切换分布，须有稳定优先级 | M4 |

每个数字依次抽取“数值 → 空格位置”，生成后立即移出空格候选。没有可用空格时不抽数值。基础实现要求单次权重总和不超过 2³²−1，超出时提示约分或降低权重。生成数量为 0 时，未使用的全零分布允许保存并提示；不能因此禁止不生成数字的玩法。

## 5 移动与合并

**界面：** 自定义设置 → 移动 / 合并。经典规则中的无效方向输入不消耗随机数、不生成节点、不计入有效操作。

| 字段 | 类型 | 默认值 | 合法范围与行为 | 阶段 |
|---|---|---|---|---|
| `movement.directions` | 方向数组 | 上右下左 | 不重复；空数组允许并提示 | M1/M3 |
| `movement.distance` | 枚举 | `slide` | 滑到底；单格移动后续开放 | M1/P2 |
| `movement.invalidMovePolicy` | 枚举 | `ignore` | `ignore` 或 `advance-round`；后者明确计入操作并按规则结算 | M3 |
| `movement.wrap` | 枚举 | `none` | 环绕须定义停靠和冲突次序，未支持时拒绝启动 | P2 |
| `merge.kind` | 枚举 | `equal-sum` | 同值求和、mapping 映射、sequence-next 相邻数列 | M1/M4 |
| `merge.maxMergesPerTile` | UInt | 1 | 1–64；经典新块同一次移动不能再次合并 | M1/M4 |
| `merge.chain` | bool | false | 开启时受事件与合并预算约束 | M4 |
| `merge.mappings` | 映射数组 | `[]` | A、B、结果、方向性、优先级；循环仍受运行预算限制 | M4 |
| `merge.ruleOrder` | 规则 ID 数组 | `[]` | 先优先级，再显式顺序、ASCII ID；不可依对象遍历顺序 | M4 |
| `score.method` | 枚举 | `merged-value` | 经典按新合并值计分；其他方法按能力声明开放 | M1/M4 |
| `score.multiplier` | UInt | 1 | 可为 0；以精确整数计算 | M3 |

移动顺序按方向从靠近目的边界的一端开始，同一行或列的合并先后固定。`[2,2,2,2]` 向左应为 `[4,4,空,空]`、加 8 分；`[4,4,8,空]` 向左应为 `[8,8,空,空]`、加 8 分。

## 6 技能

**界面：** 自定义设置 → 技能。路径写作 `skills.<skillId>.<字段>`。正常模式全部关闭；建议自定义起步预设开启撤销 3 次，其余技能默认关闭。

| 公共字段 | 类型 | 默认值 | 合法范围与行为 |
|---|---|---|---|
| `enabled` | bool | 撤销 true，其余 false | 关闭时隐藏无效子参数；状态数据仍可完整导出 |
| `unlimited` | bool | false | 无限只取消次数限制，不取消冷却、目标与分数成本 |
| `initialCharges` | UInt | 3 | 新局余量；不高于最大储量 |
| `maxCharges` | UInt | 3 | 可为 0，表示当前无法施放 |
| `cooldownTurns` | UInt | 0 | 使用后设置；当前技能不在本次结算中立刻减掉自己的新冷却 |
| `rechargeEveryTurns` | UInt 或 null | null | null 不恢复；否则 ≥1，按未被撤销的累计计费回合推进 |
| `rechargeAmount` | UInt | 1 | 恢复后不超过最大储量 |
| `scoreCost` | IntText | `"0"` | 成本不能导致分数为负；撤销需检查恢复后的分数能否支付 |
| `advanceRound` | bool | 撤销 false，其余 true | 独立于有效操作计数；撤销成功仍计入有效操作【D03】 |
| `spawnAfterUse` | bool | false | 与全局生成触发条件取或；同一操作只生成一批 |
| `allowAfterLoss` | bool | 撤销 true，其余 false | 还需合法目标和可用资源；可挽救判定应考虑此字段 |
| `params` | 对象 | 按技能定义 | 不接受任意宿主脚本 |

| 技能 ID | 效果和目标 | 专属参数建议 | 阶段 |
|---|---|---|---|
| `undo` | 恢复最近一个可撤销动作前的世界状态 | `scope="world"`；具体恢复表见数据契约 | M3 |
| `delete` | 删除一个数字块 | 单个非空格；可设置保护最大数字 | M3 |
| `swap` | 交换两个不同格子的内容 | 允许与空格交换；不能选墙或禁用格 | M3 |
| `upgrade` | 按规则提升一个数字块 | 经典乘 2；自定义数列时取下一项 | M3/M4 |
| `downgrade` | 按规则降低一个数字块 | 经典偶数除 2；无合法前项时拒绝 | M3/M4 |
| `shuffle` | 重排可用格中的数字与空位 | 保护格不参与；结果偶然相同也算成功 | M3 |
| `spawn` | 向空格放指定数字 | IntText 与目标索引必须合法 | M3 |
| `clear-line` | 清空指定行或列 | 轴、索引、保护格策略 | M3 |
| `rotate` | 旋转棋盘内容 | 90/180/270 度；非方形 90 度需明确是否交换尺寸 | M3/M4 |

成功技能一律“操作数 +1 → 新节点 → 自动保存”【D03、D04】。不合法、次数不足、冷却中和支付失败均拒绝，不消耗次数。编辑器里的“撤销编辑”仅撤销未提交草稿；游戏里的撤销技能与时间树导航分别处理。

## 7 事件与高级规则

**界面：** 自定义设置或修改规则 → 高级规则 → 触发 / 条件 / 动作【D11】。M4 已提供受控事件，实际时点、迁移和预算见 [M4 操作说明](高级沙盒_M4.md)。

| 字段 | 类型 | 默认值 | 校验与执行约定 |
|---|---|---|---|
| `events[].id` | ID | 新建时生成 | 规则版本内唯一 |
| `events[].trigger` | 枚举 | `after-round` | 移动后、合并后、技能后、生成前后、回合后、编辑/发布后；逻辑时间未开放 |
| `events[].condition` | 条件树或 null | null | 有类型的比较、且、或、非；null 为无条件 |
| `events[].actions` | 受控动作数组 | 增加成绩 1 | 至少 1 个：放/删数字、加成绩、设/加变量、补技能次数、发触发信号 |
| `events[].priority` | 安全整数 | 0 | 优先级相同时按 ID 排序 |
| `events[].maxExecutions` | UInt 或 null | 1 | null 表示规则级不设次数，仍受单步总预算限制 |
| `events[].cooldownTurns` | UInt | 0 | 与对应规则版本的事件运行状态关联 |
| `events[].allowReentry` | bool | false | 同次结算默认不重入同一规则 |
| `variables` | IntText 初值映射 | `{}` | 名字为 ASCII 标识符；值为精确非负整数，运行值属于世界状态 |

事件预算耗尽时整步回滚，保留诊断，不提交截断后的半步结果。脚本、分数、负数和任意公式属于后续扩展；导入包含未实现能力的规则应说明原因或只读打开。

## 8 胜负与计时

**界面：** 自定义设置 → 胜负计分 / 系统。各目标为独立字段；全部关闭可以形成无尽玩法。

| 字段 | 类型 | 默认值 | 合法范围与行为 | 阶段 |
|---|---|---|---|---|
| `goals.tileValue` | IntText 或 null | `"2048"` | null 关闭；达到或超过该值为完成 | M1/M3 |
| `goals.scoreTarget` | IntText 或 null | null | null 关闭，0 允许并提示可能开局完成 | M3 |
| `goals.winPolicy` | 枚举 | `any` | 已启用目标取任一或全部；没有目标时不自动胜利 | M3 |
| `goals.continueAfterWin` | bool | true | 获胜后仍记录首次获胜事件 | M1/M3 |
| `goals.roundLimit` | UInt 或 null | null | null 不限，启用时 ≥1；规则回合数达到上限判定 | M3 |
| `goals.lossWhenNoMoves` | bool | true | 考虑被允许的挽救技能后再判不可继续 | M1/M3 |
| `goals.allowRescueSkills` | bool | true | 仅判断已启用、可支付、有合法目标且允许失败后使用的技能 | M3 |
| `timer.mode` | 枚举 | `none` | `none`、`elapsed`、`countdown` | M3/M4 |
| `timer.limitMs` | UInt 或 null | null | 倒计时时 ≥1，其余为 null | M4 |
| `timer.pauseWhenHidden` | bool | true | 页面隐藏暂停；逻辑经过时间显式进入操作或计时事件 | M4 |

同一步先结算效果、生成与计分，再更新目标和结局。若胜利与失败同时满足，先记录胜利，随后保留不可继续的终止原因。恢复对局的实际运行计时默认暂停【D10】，不按离开时长补扣。

## 9 项目与展示设置

**界面：** 游戏项目 → 设置；字段相对于 `Project.preferences`。以下设置不改变经典规则身份。

| 字段 | 类型 | 默认值 | 行为 | 阶段 |
|---|---|---|---|---|
| `randomBranchPolicy` | 枚举 | `reroll` | 可切换 `reproduce`；仅影响新操作，不改写既有历史【D02】 | M2 |
| `snapshotEveryActions` | UInt | 32 | ≥1；根节点、规则变化、撤销与导出边界强制检查点 | M2 |
| `compression` | 枚举 | `deflate` | 默认启用无损压缩【D12】；兼容导入可读取未压缩条目 | M2 |
| `deduplicateSnapshots` | bool | true | 按完整快照内容去重，不合并节点【D08、D12】 | M2 |
| `exportIncludeArchived` | bool | true | 完整备份默认包括归档分支；局部分享可关闭并标示范围 | M2 |
| `theme` | 枚举 | `system` | 跟随系统、浅色、深色 | M1/M5 |
| `motion` | 枚举 | `system` | 跟随系统、正常、减弱；不影响结算结果 | M1/M5 |
| `tileDisplayDigits` | UInt | 10 | 超长数字缩写，详情保留精确值 | M3 |

资源预算建议单列：棋盘 4096 格、单步事件 10000 个、链深度 64、整数 256 位、解压总量 256 MiB、条目 100000 个、压缩比 200。它们是初始可调策略，需性能验证；提高预算不应迁移或删除历史。无法处理时拒绝本次请求并保留已保存状态。

## 10 校验与修改规则

| 情形 | 结果 |
|---|---|
| 非整数尺寸、越界索引、负数值、必需抽样却全零权重 | 错误，阻止开始并定位字段 |
| 零生成、没有移动方向、目标可能不可达、1×1 棋盘 | 提示或警告，允许特殊玩法 |
| 缩小棋盘会丢失数字 | 默认取消；预览明确列出受影响格子，由玩家选择迁移策略 |
| 对局中调整技能储量 | 保留已有资源并按新上限裁剪；无限切有限时显示明确初始余量 |
| 对局中改变规则 | 新版本 + 子节点；建议清空技能撤销栈形成版本边界，历史树仍可回到旧规则 |
| 改主题、查看节点、切随机偏好 | 更新项目设置或会话，游戏节点不变 |

可恢复状态和动作的细节见 [状态与历史数据契约](状态与历史数据契约.md)，文件范围与导入校验见 [存档格式草案](存档格式草案.md)。
