# 2048 Sandbox 交互与统计 M5

**日期：** 2026 年 10 月 14 日  
**应用版本：** 0.7.0  
**范围：** 完善已有编辑、历史与分析交互，保持规则、状态和存档兼容。

## 1 批量棋盘编辑

“编辑本节点棋盘”新增“绘制范围”：单格或矩形区域。矩形模式依次点选两个角，对包含边界的整个矩形填入画笔数字；配合清空画笔可批量擦除。反向点选两个角得到相同区域，数字 0 仍占格。

只选第一个角时不修改草稿，提交按钮暂不可用；可“取消区域”重新选。完成区域后只增加一个草稿版本，撤销/重做一次即可恢复整批。底部固定显示修改格数和提交按钮。

选择、取消、撤销草稿与关闭窗口均免费。最终提交仍是 M4 的一笔棋盘编辑节点，增加一次有效操作，不按格数收费。尺寸、规则边界、技能撤销和编辑后事件沿用 [M4 语义](高级沙盒_M4.md)。

## 2 图形规则维护

设置窗口增加棋盘、生成移动、目标、技能、高级合并和事件导航；跳转会打开相关折叠区域。条件编辑器显示自然语言摘要，支持比较、且、或、非，切换为组合条件时保留已有条件。

事件根条件可选“总是满足”；阶段与组合子项必须是具体条件，不再把“总是”悄悄替换成默认比较。条件和动作仍经过结构、引用、深度与资源预算校验。

变量改名自动同步阶段条件、事件条件和设置/增加变量动作中的引用。重名、非法名称或保留名会拒绝修改，原变量和引用保留。对局中发布改名仍按 M4 的删除旧变量、创建新变量迁移规则执行，**新变量使用配置初值**，界面对此给出提示。

事件可复制，副本具有新 ID，自身执行次数条件引用也同步到副本。动作可复制、上移和下移，同一事件的动作按界面顺序执行；事件之间仍按优先级和稳定 ID 排序，复制不改变这条语义。

## 3 规则状态与节点对比

左侧“规则与路径统计”打开只读分析窗口，也可从历史树的“查看路径统计”进入。

“规则状态”读取当前预览节点自己的规则版本，显示棋盘、世界/计费回合、有效操作、合并方式、当前条件下的生成阶段、目标与结束状态、变量、事件执行次数/冷却/条件，以及技能资源。

事件显示次数已达上限、冷却、条件未满足或等待对应触发。这里展示提交后的状态，不伪造本步执行日志；生成前事件可能改变下一步实际命中的生成阶段。

“节点对比”以保存位置、父节点、统计起点或统计终点为基准，比较所选节点。数字按坐标对齐，区分 0、空格和无此格；同时显示成绩、规则、回合、随机流、技能资源、变量和事件状态差异。规则标识与摘要可展开查看，棋盘差异每批显示 100 条。

## 4 路径统计

统计范围为根到所选终点的唯一父链，包含路径中的撤销、棋盘编辑和规则发布。打开时固定终点；图表或表格回看其他节点不会自动缩短统计路径，可用按钮重新设定终点。

| 指标 | 计算口径 |
|---|---|
| 路径最高成绩 | 所有路径节点成绩的最大值，包含后来被撤销的节点 |
| 路径最大数字 | 路径中出现过的最大数字，包含后来消失的数字 |
| 路径有效操作 | 路径长度减根节点，成功技能和编辑均计数 |
| 实际合并累计 | 相邻节点合并计数的正向增量之和，撤销不减掉之前实际发生的合并 |
| 经历规则版本 | 路径实际 ruleRef 的去重数量，规则 ID 与版本一起比较 |
| 路径检查点 | 位于该父链上的检查点数量 |
| 全局节点/分叉 | 当前项目全部节点及拥有多个子节点的节点数量，包含归档 |

方向移动、技能、棋盘编辑和规则发布分别计数。其他分支不会混入路径最高成绩或操作数；全局节点/分叉明确单独展示。

趋势图保留撤销导致的下降，最多抽样 200 点，并保留起点、终点、峰值和所选路径节点。滑块和逐步记录可回看未绘制的其他节点。逐步记录支持操作类型筛选，每页 50 条。

成绩、最大数字、正向成绩变化累计与逐步成绩变化使用精确整数。图表仅把已缩放到 0–100 的比例转为显示坐标，不把原成绩直接转成浮点数。统计、回看、切换标签和下载均不写数据库。

## 5 分析报告

“下载统计 JSON”输出 format=2048-sandbox-path-statistics、formatVersion=1、projectId、exportedAt、endId、rows、actions、skills 和聚合指标。每行包含节点 ID、深度、动作类别/显示名、精确成绩/变化、世界回合、有效操作、ruleRef 和 stateHash。

该文件是独立分析报告，供查看或外部处理；恢复游戏继续使用 .2048state / .2048lab / .2048backup。示例放在 [examples/statistics](../../examples/statistics/README.md)，与可导入游戏存档分开。

## 6 历史树与手机交互

树按深度列和纵向区间建立索引，只创建当前视口附近的节点与连线；密集视口最多绘制 2000 条连线，并显示限制提示。总览展示当前展开和过滤结果，点选可定位视口。选中节点的祖先路径高亮。

大于 120 节点时，初次打开定位所选节点附近；支持适应全树、定位所选、定位保存节点和跟随所选。查找优先匹配完整 ID 和精确步数，再匹配 ID 片段，最多显示 30 条结果。隐藏或折叠的目标可展开定位。

空白画布支持拖动、滚轮和双指缩放；总览也支持方向键。画布获焦时方向键平移、Home 适应；节点获焦时左右键转到父/首个子节点，上下键切换同级，焦点跟随新节点。选择与回放均免费，不改变保存位置。

主页面历史列表改为每页 60 条，外部回看时自动定位所选记录所在页。手机使用同一套区域选择、导航、分析与树控制；常规内容保持窗口内，宽表格在自己的容器内横向滚动。

从历史预览点击“新开一局”，沿用正在展示的规则版本；原项目和所有路径保留。这与“复制当前规则”的显示上下文一致。

## 7 兼容与验收边界

M5 不增加依赖、不增加规则能力、不修改核心 Schema、数据库 v3 或容器 v1。游戏结算、迁移和事件引擎保持 M4 内容，新增状态仅用于临时界面。

本轮验证 10000 节点深链的布局/视口查询、3000 子节点密集连线限制，以及真实 301 节点存档的浏览器导入、导航与完整报告。它们不是全项目规模或帧率承诺；大型项目完整回放/存储性能和不同树形仍留待 M6 验收。

计时、保护格、非方形 90/270° 旋转、任意脚本和未知规则只读导入继续未开放。证据见 [M5 验收记录](../planning/M5_验收记录.md)，后续见 [实施计划](../planning/项目整理与实施计划.md)。
