# 2048 Sandbox 基础沙盒 M3

**日期：** 2026 年 10 月 14 日  
**应用版本：** 0.5.0  
**状态：** 基础自定义与九种基础技能已实现。本文说明实际行为；D01–D12 与 v0.2 产品基线继续有效。

## 1 新开自定义对局

点击“自定义新局”，可从基础沙盒、经典参数或当前规则的副本开始。草稿编辑、提示和取消都不写入对局。点击“创建自定义对局”后，新规则与根节点一起自动保存。

“新开一局”沿用当前规则并保留旧局。设置窗口的“直接开始经典对局”使用固定经典规则。对局中修改既有规则、编辑棋盘和规则版本迁移留在 M4。

| 设置 | M3 行为 |
|---|---|
| 行列 | 独立为 1–64，最多 4096 格；大棋盘在容器内滚动 |
| 初始布局 | 格索引从 0 开始，按行排列；先放布局，再补足开局数量 |
| 数字 | 非负精确整数，0 占格；位数预算 1–4096，默认 256 |
| 允许数字 | 留空表示不限；限制初始布局、生成与放置，不限制合并/升级结果 |
| 两套权重 | 开局与回合分别配置“数字:权重”，总权重不超过 4294967295 |
| 生成数量 | 可为 0；空间不足时生成至填满或整批跳过 |
| 生成触发 | 移动或规则回合，可同时选；同一操作只生成一批 |
| 移动 | 可选择四个方向；无效输入默认忽略，也可明确计入操作并推进回合 |
| 计分 | 同值相加、每步每块合并一次；合并值乘以非负整数倍率 |
| 目标 | 数字目标、成绩目标，任一/全部，可全部关闭形成无尽玩法 |
| 结束 | 胜利后继续开关、回合上限、无路可走判负与挽救技能 |

权重为整数比例，按数组顺序抽样；先抽值，再从升序空格索引中抽位置。没有可用空格时不抽值；整批跳过不抽随机数。开局数量小于明确布局时保留全部布局并提示。

需要抽样但总权重为 0、重复值、索引重复/越界、数字超预算、初始技能次数超过储量等会阻止创建并定位字段。1×1、零生成、空方向或目标关闭等特殊玩法给出提示，允许创建。

## 2 技能操作

正常模式关闭全部技能；基础沙盒默认只开启撤销 3 次。其余技能可在新局设置中开启。

| 技能 | 目标与效果 |
|---|---|
| 撤销 | 直接点击，恢复最近一个可撤销操作之前的世界状态 |
| 删除 | 选一个非空格，删除数字 |
| 交换 | 选两个不同格子，至少一个非空；允许与空格交换 |
| 升级 | 选正数乘 2，不产生合并计分；0 与超预算结果拒绝 |
| 降级 | 选不小于 2 的偶数除以 2，其他值拒绝 |
| 洗牌 | 对全棋盘的数字与空位执行确定性 Fisher–Yates；结果相同仍算成功 |
| 放置 | 选空格并输入允许的非负整数，0 也可以放置 |
| 清空行列 | 选行/列及从 1 开始的序号，空行列拒绝 |
| 旋转 | 方形支持顺时针 90/180/270°；非方形本阶段仅支持 180° |

选格期间移动输入暂停，选择、改选或取消不会写节点。技能非法、次数不足、冷却中、成本不足均不消耗资源；成功时结算一次、创建子节点并自动保存。每种技能都能配置有限/无限次数、最大储量、冷却、恢复间隔/数量、成绩成本、推进回合、施放后生成及失败后使用。

大棋盘使用原生触摸滚动查看内容，移动使用方向按钮或键盘；常规棋盘保留滑动操作。节点回看与路径回放始终免费。

## 3 撤销与资源

例如 S0→S1→S2，操作次数为 0→1→2，成绩为 0→4→12。在 S2 撤销创建 U1，父节点仍是 S2，undoTargetId 为 S1：棋盘、成绩、世界回合、合并次数、目标和世界计时恢复到 S1，但有效操作数成为 3、撤销次数从当前的 3 扣到 2。

再撤销创建 U2，父节点为 U1，恢复 S0，有效操作数成为 4，撤销次数变成 1。原 S1/S2/U1 仍在历史树中，免费回看不会改变这些数据。

- 撤销栈记录成功非撤销操作的父节点；撤销弹出栈顶，不把自身入栈。
- 世界状态取目标，技能余量、使用量、冷却和恢复进度取当前节点，再结算本次成本。
- 成绩成本以恢复后的成绩判断，不能用撤销前的高分支付、再产生负数。
- 随机流从当前节点继承，撤销分支也不重抽或倒带；若配置生成，沿继承的流继续抽样。
- 默认撤销不推进规则回合；开启推进后，在恢复的世界回合上加 1，当前累计计费回合也加 1。
- M3 一个对局使用一个不可变规则版本；跨版本撤销拒绝。

所有技能的冷却与恢复都使用不会随世界恢复倒退的累计计费回合。只有移动或开启“推进规则回合”的技能推进它；有效操作数与计费回合分别保存。使用的技能保留新设置的冷却，不在本次立即减 1。有限技能在恢复间隔到达时补充次数，最多到最大储量；本次推进的回合也计入恢复间隔。

无限只取消次数限制，目标、冷却与成绩成本仍生效。保存失败整体回滚；重试沿用同一操作 ID、目标与随机输入，不重复扣资源。

## 4 胜负与挽救

结算顺序为效果与成本、资源计费、生成，再更新目标和结局。已完成目标保存在世界状态中，撤销可恢复其原有记录；所有启用目标完成时记录首次胜利时刻。没有目标时不自动胜利。

无路可走时，挽救判定检查启用、次数、冷却、成绩、合法目标及“失败后可用”。仍有可施放技能时显示可挽救状态；施放后重新判定。回合上限到达后，只允许能够恢复到上限前的撤销，不以其他技能绕过上限。胜利后继续关闭时，本局按规则结束。

## 5 文件与兼容

继续使用 [存档格式 v1](存档格式_v1.md)，未改写旧文件或旧节点。自定义规则声明 sandbox-v1；启用技能时还声明 skills-v1。混合项目库可同时包含经典与自定义对局，导入按实际 ruleRef 加载并回放验证。

副本保留节点 ID、undoStack、undoTargetId、资源、随机流和状态摘要；项目 ID 在本地重新映射。撤销节点强制保存完整快照，其依赖随节点/路径文件一起导出。本地数据库表结构保持 M2 的 v3，M1 数据仍可自动升级。

M3 可恢复 M1/M2 文件；旧 M2 应用没有新能力，不能执行 M3 自定义文件。未知能力、坏摘要或缺恢复目标在写入前拒绝。示例文件见 [演示存档](../../examples/projects/README.md)。

## 6 后续边界

计时对局、对局中规则编辑、缩放棋盘的迁移、自定义数列、障碍/保护格、动态概率、触发条件动作与脚本未开放。4096 格与整数预算是拒绝边界，未宣称这些边界上的完整应用性能已验收。
