# 可导入规则预设

`classic.json` 与 `sandbox.json` 是原有产品契约样例，保持原文。M6 增加以下实际引擎可使用的配置，在“文件与恢复”中导入规则 JSON 可创建新局；也可直接在“自定义新局 → 探索预设玩法”中选择。

| 文件 | 玩法与首步检查 |
|---|---|
| [连锁合并](m6/chain.json) | 1×4，2、2、4、8 向左连成 16，三次合并共 28 分；不自动生成 |
| [斐波那契](m6/fibonacci.json) | 1+1=2，相邻数列项相加；首步向左得 2 分，目标 1597 |
| [技能练习场](m6/skills.json) | 九种技能各 3 次，关闭自动生成、数字目标和无路可走判负 |
| [阶段与奖励](m6/stages.json) | 3×5，第 3 回合起只生成 4；合并加 10 分，最多奖励 10 次；首步向左得 14 分 |

预设由 [catalog.ts](../../src/presets/catalog.ts) 生成，真实摘要已写入文件。修改预设后运行 `node scripts/export-presets.mjs` 更新 M6 文件，再运行 `pnpm test` 验证语义、摘要、导入及样例与界面一致。生成器只更新 `m6/`，不会改写原有契约样例。

选择界面预设只填写草稿，点击创建才保存；对局内修改规则仍通过独立的迁移预览与新版本发布完成。
